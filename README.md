# Weather Service

## Description
This is a weather service that ingests weather data from an external API and provides it via a RESTful API.

## Requirements
- Node.js
- MongoDB

## Installation
1. Clone the repository.
2. Navigate to the project directory.
3. Install the dependencies:
   ```bash
   npm install
## How to use
1. nodemon install
2. nodemon server.js
3. then go to your browser
4. first type http://localhost:5000
5. then type https://localhost:5000/weather/data
6. you can check weather data by https://localhost:5000/weather/data?lat=42&lon=-74.5
7. you can check batches http://localhost:5000/weather/batches
